# Obsidian — локальная база знаний

Obsidian — центр личных заметок экосистемы: ежедневные записи, исследовательские черновики и рабочие материалы. Хранилище (vault) лежит в OneDrive и защищено двумя независимыми контурами резервирования — облачной синхронизацией OneDrive и ежедневным Git-бэкапом на GitHub.

## Расположение и структура

```
OneDrive\Obsidian\Vault\
├── Daily\          # ежедневные заметки (создаются автоматически в 07:00)
├── Research\       # исследовательские заметки и черновики статей
├── Projects\       # рабочие материалы по проектам
├── templates\      # шаблоны заметок (исключены из синхронизации)
└── archive\        # архив (исключён из синхронизации)
```

Папки `.obsidian`, `.git`, `templates` и `archive` не участвуют в синхронизации с Notion.

## Автоматизация

| Задача | Расписание | Скрипт |
|--------|-----------|--------|
| Создание ежедневной заметки | 07:00 ежедневно | `New-DailyNote.ps1` |
| Git-бэкап хранилища на GitHub | 18:00 ежедневно | `Backup-ToGitHub.ps1` |
| Публикация заметок в Notion | по запросу | `Sync-ObsidianToNotion.ps1` |

Задачи регистрируются в Планировщике заданий Windows; состояние проверяется дашбордом `Get-WorkspaceStatus.ps1`.

## Публикация заметок в Notion

В Notion попадают только заметки, явно помеченные к публикации. Пометить заметку можно любым из способов:

1. **Инлайн-тег** в тексте заметки:

   ```markdown
   Итоги эксперимента готовы к обсуждению с командой. #publish
   ```

2. **Тег во frontmatter**:

   ```yaml
   ---
   tags: [research, publish]
   ---
   ```

3. **Флаг публикации** во frontmatter:

   ```yaml
   ---
   publish: true
   ---
   ```

Остальные заметки остаются приватными. Подробности синхронизации — в [docs/notion.md](notion.md).

## Рекомендации

- **Frontmatter — для метаданных.** Теги, статус и даты держите в YAML-блоке в начале заметки: при публикации в Notion frontmatter автоматически отсекается и не засоряет страницу.
- **Одна заметка — одна тема.** Заметки публикуются в Notion как отдельные страницы с названием из имени файла; атомарные заметки дают чистую структуру на стороне команды.
- **Следите за размером.** Страница Notion принимает до 100 блоков за один запрос; более длинные заметки усекаются. Проверка «здоровья» хранилища (`Sync-ObsidianToNotion.ps1`) предупреждает о файлах крупнее 500 КБ.
- **Не переименовывайте опубликованные заметки без необходимости.** Соответствие «файл → страница Notion» хранится в состоянии синхронизации по относительному пути файла; после переименования будет создана новая страница.
